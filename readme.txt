Add a customizable, SEO-friendly Table of Contents block to WordPress posts & pages — auto-generated from your headings in the Block Editor.

== Description ==

**Table of Contents** is a roadmap for your whole content and helps your readers to locate specific parts of the page to go directly to that section.

Using Table of Contents Block (TOC), you can improve the reading experience, accessibility, page SEO score & help your visitors to easily navigate.

You don’t need any coding to create TOC in Gutenberg. Just install this block plugin & use Table of Content within Block Editor for WordPress.


**⚙️ Completely Customizable:** You can customize and pick the heading tags which you want to appear on your Table of Contents.

**⚡ Super Light-weight:** No extra resources used and it's highly optimized to automatically add Table of Contents inside your post or pages.

== Installation ==

**Modern Way (from the Block Editor):**

1. Go to the WordPress Block/Gutenberg Editor
2. Search for "Table of Contents Block" in the block inserter
3. Install & activate in 1-click

**From your WordPress Dashboard:**

1. Go to Plugins → Add New
2. Search for "Table of Contents Block"
3. Click Install Now, then Activate

**Manual Installation:**

1. Upload the `table-of-contents-block` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Add the Table Of Contents block to any post or page from the block inserter


== Frequently Asked Questions ==

= Does it work with all themes? =

Yes, it works with any standard WordPress theme, including classic themes and modern block themes with Full Site Editing.

= Which heading blocks are detected? =

All of them. The Table of Contents is generated from every H1–H6 heading in your content, so headings from the core Heading block and any third-party block library (Essential Blocks, Kadence, Stackable, Spectra, GenerateBlocks & more) are picked up — including headings nested inside Groups, Columns & patterns.

= Can I choose which heading levels appear in the Table of Contents? =

Yes. From the block settings you can toggle each heading tag (H1–H6) individually, and you can also exclude specific headings from the list.

= Can I make the Table of Contents sticky or collapsible? =

Yes. The block includes a sticky mode (pinned to the left or right of the screen), a collapsible mode with an optional initially-collapsed state, presets, smooth scrolling, a copy-link button for headings and a scroll-to-top button.

= Will this plugin slow down my website? =

No. The block is super lightweight — its small script & stylesheet are only loaded on pages that actually contain a Table of Contents block.

= Is it compatible with the latest WordPress? =

Yes. Version 1.5.0 is tested up to WordPress 7.0 with the latest Gutenberg, supports the iframed Block Editor, and works on PHP 7.4 through 8.3.
